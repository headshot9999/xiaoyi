## 二、一键嵌入本机照片使用方法

由于云端运行环境无法直接访问您 Mac 本机的 `/Users/jiangxiaoyi/sam's document/公司旅游心得/5周年旅游照片` 文件夹，仓库内的 `.pptx` 已为您预置了带景点说明的精美取景占位框。

您在本地 Mac 上只需运行以下命令，脚本会自动读取该目录下的照片、智能按比例居中裁剪（不拉伸变形）并生成带真实照片的 PPT：

```bash
pip install -r requirements.txt
python3 generate_travel_ppt.py
```

如果您的照片存放在其他路径，也可以通过 `--photos` 参数指定：

```bash
python3 generate_travel_ppt.py --photos "/Users/jiangxiaoyi/sam's document/公司旅游心得/5周年旅游照片" --output "艾多美5周年员工旅游心得_上海杭州.pptx"
```

### 智能照片匹配规则

- **关键词优先匹配**：若照片文件名中包含对应关键词（如 `全家`、`外滩`、`金茂` / `自助`、`豫园`、`城隍庙`、`南京路`、`西湖`、`雷峰塔`、`龙虾`、`面包蟹`），脚本会自动将照片精准放入对应页面槽位。
- **顺序自动补齐**：若照片采用相机默认命名（如 `IMG_0001.JPG`），脚本会自动按文件名顺序依次填入 10 个照片框中，并自动处理手机照片的 EXIF 旋转方向。
