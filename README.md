# 服务达人挑战赛 · 页面 UI

「服务达人挑战赛」活动页面的前端 UI 设计示例。页面展示某位服务达人名下**绑定成功的会员列表**，包含会员号、绑定时间，以及每位会员每月为其贡献的积分，并支持按会员号、月份、绑定时间等条件查询。

## 功能特性

- **顶部活动横幅**：展示赛季信息与当前服务达人卡片（昵称、工号、赛季排名）。
- **数据概览卡片**：绑定成功会员数、本月贡献积分、累计贡献积分、本月活跃会员数（随筛选结果联动）。
- **多条件查询**：
  - 按 **会员号 / 昵称** 关键字搜索（输入即时筛选）。
  - 按 **月份** 查看某月贡献积分，或切换为「全部月份（累计）」。
  - 按 **绑定时间** 起止区间筛选。
  - 多种 **排序**：所选月积分、累计积分、绑定时间。
- **会员明细表**：排名（前三名金银铜牌样式）、会员号、昵称、绑定时间、当月/累计贡献积分、本月活跃状态。
- **激活筛选标签**：当前生效的筛选条件以可一键移除的标签展示。
- **分页**：每页 8 条，带省略号的智能分页。
- **导出**：将当前筛选结果导出为 CSV（含 BOM，Excel 可直接打开中文）。
- **响应式布局**：适配桌面、平板与手机。

## 运行方式

纯静态页面，无需构建。直接用浏览器打开 `index.html` 即可，或在目录下启动一个本地静态服务器：

```bash
# 任选其一
python3 -m http.server 8080
# 然后访问 http://localhost:8080
```

## 文件结构

- `index.html` —— 页面结构
- `styles.css` —— 样式（主题色、卡片、表格、响应式）
- `app.js` —— 模拟数据生成与查询 / 排序 / 分页 / 导出等交互逻辑

> 说明：页面中的会员与积分数据均为**前端模拟生成**（使用固定随机种子，保证每次刷新一致），仅用于 UI 演示，接入真实接口时替换 `app.js` 中的数据来源即可。
