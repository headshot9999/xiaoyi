# 服务达人挑战赛 · 移动端页面 UI

「服务达人挑战赛」活动页面的前端 UI 设计示例（**移动端**）。页面展示某位服务达人名下**绑定成功的会员列表**，包含会员号、绑定时间，以及每位会员每月为其贡献的积分，并支持按会员号、月份、绑定时间等条件查询。主色采用 **艾多美蓝 Atomy Blue**（PANTONE 2995C / RGB 0,181,239 / `#00B5EF`）。

## 功能特性

- **顶部头部**：服务达人卡片（昵称、工号、赛季排名）+ 数据概览（绑定会员数、本月贡献积分、累计贡献积分）。
- **多条件查询**：
  - 按 **会员号 / 昵称** 关键字搜索（输入即时筛选）。
  - 按 **月份** 查看某月贡献积分，或切换为「全部月份（累计）」。
  - 按 **绑定时间** 起止区间筛选。
  - 多种 **排序**：所选月积分、累计积分、绑定时间。
- **会员卡片列表**：排名（前三名金银铜牌样式）、会员号、昵称、绑定时间、当月/累计贡献积分。
- **会员积分贡献明细**：点击任意会员卡片，弹出该会员的积分贡献明细（绑定时间、累计积分，以及按月贡献积分的可视化进度条）。
- **绑定会员**：右下角悬浮「绑定会员」按钮，可输入会员号 / 昵称绑定新会员（带重复校验）。
- **加载更多**：移动端友好的分页方式（每次 6 条）。
- **移动端 UI**：手机端布局，桌面端居中呈现为手机预览样式。

## 运行方式

纯静态页面，无需构建。直接用浏览器打开 `index.html` 即可，或在目录下启动一个本地静态服务器：

```bash
# 任选其一
python3 -m http.server 8080
# 然后访问 http://localhost:8080
```

## 文件结构

- `index.html` —— 移动端页面结构
- `styles.css` —— 样式（艾多美蓝主题、卡片、弹层、响应式）
- `app.js` —— 模拟数据生成与搜索 / 筛选 / 排序 / 明细 / 绑定 / 加载更多等交互逻辑

> 说明：页面中的会员与积分数据均为**前端模拟生成**（使用固定随机种子，保证每次刷新一致），仅用于 UI 演示，接入真实接口时替换 `app.js` 中的数据来源即可。
