# 艾多美 5 周年员工旅游心得 PPT

本项目包含 **《艾多美5周年员工旅游心得.pptx》**（共 6 页，16:9 宽屏版式）以及自动配图生成脚本 `make_travel_ppt.py`。

## PPT 页面结构（共 6 页）

1. **第 1 页 · 封面**：《五年同行，感恩有家 —— 上海·杭州全家幸福之旅心得分享》，突出入职满 5 周年福利、三代同行概览与全家福大图。
2. **第 2 页 · 福利与初心**：展示艾多美每满 **3、5、7、10 年**由公司承担费用的员工旅游制度，携父母、老婆、孩子一同出游的初心与路线规划。
3. **第 3 页 · 上海站（繁华与云端）**：漫步**外滩**与**南京路步行街**，登上**金茂大厦 56 层**享用 **300元/位** 的高空观景自助餐。
4. **第 4 页 · 上海站（江南古韵）**：游览**豫园**古典园林与**老城隍庙**，陪父母与妻儿感受传统建筑与地道市井烟火气。
5. **第 5 页 · 杭州站（山水与盛宴）**：漫步**西湖**、登高**雷峰塔**，全家围坐共享**大龙虾、面包蟹**等丰盛海鲜大餐。
6. **第 6 页 · 心得与感恩**：总结 5 周年旅游感悟，把公司的关怀与家人的支持化作未来奔赴 7 周年、10 周年的工作动力。

## 一键填入本机照片

由于云端环境无法直接读取您本机 Mac 硬盘上的 `/Users/jiangxiaoyi/sam's document/公司旅游心得/5周年旅游照片`，脚本已默认预设好该路径。您在本地电脑只需执行以下命令，即可将文件夹中的照片（支持 `.jpg` / `.png` / `.heic` / `.webp`）自动裁剪、修正方向并嵌入每一页 PPT：

```bash
pip3 install -r requirements.txt
python3 make_travel_ppt.py
```
