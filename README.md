## 如何在你本地电脑自动填入真实照片

由于当前运行在云端环境中，无法直接访问你 Mac 本地的 `/Users/jiangxiaoyi/sam's document/公司旅游心得/5周年旅游照片` 文件夹，你可以任选以下两种方式将照片放入 PPT：

### 方式一：在 Mac 本地运行脚本一键自动配图（推荐）

1. 将本分支代码拉取到本地电脑后，在终端执行：
   ```bash
   pip3 install -r requirements.txt
   python3 generate_travel_ppt.py
   ```
2. 脚本会自动扫描 `/Users/jiangxiaoyi/sam's document/公司旅游心得/5周年旅游照片` 目录下的所有图片（支持 `.jpg` / `.jpeg` / `.png` / `.webp`）：
   - **智能关键词匹配**：如果文件名包含 `外滩`、`金茂`、`自助`、`豫园`、`城隍庙`、`南京路`、`西湖`、`雷峰塔`、`龙虾`、`面包蟹`、`海鲜`、`全家`、`父母` 等词语，脚本会自动将照片放入对应主题页面。
   - **顺序自动填充与防变形裁剪**：未命名关键词的照片也会按顺序自动填入各页相框，并按相框比例自动居中裁剪、纠正手机拍照方向（EXIF），保证照片在 PPT 中不拉伸变形。

### 方式二：直接在 PowerPoint / WPS 中右键替换图片

直接打开 `艾多美5周年员工旅游心得_上海杭州之旅.pptx`，在每页右侧/上方的照片框上 **右键 ->「更改图片」->「来自文件」**，从 `/Users/jiangxiaoyi/sam's document/公司旅游心得/5周年旅游照片` 中选择对应照片即可。
